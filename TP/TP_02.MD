## Soal

Kamu sudah menulis fungsi mulOfArray. Ujilah dengan input [2, 0, 26, 28, -2], dengan output yang seharusnya adalah 1456. Jika kamu menemukan bahwa hasilnya berbeda, bisakah kamu memperbaikinya? Jika kamu menemukan bahwa hasilnya sama, bisakah kamu menjelaskan mengapa demikian?

## Deskripsi

Program menggunakan fungsi mulOfArray untuk mengalikan seluruh elemen array yang bernilai lebih besar atau sama dengan nol.

Nilai awal variabel result adalah 1 sehingga proses perkalian dapat berjalan dengan benar. Pada setiap perulangan, program memeriksa apakah elemen array memenuhi syarat arr[i] >= 0. Jika memenuhi syarat, elemen tersebut akan dikalikan ke dalam result.

Untuk input [2, 0, 26, 28, -2], angka -2 tidak ikut diproses karena tidak memenuhi syarat. Sedangkan angka 0 tetap ikut dikalikan karena memenuhi kondisi >= 0. Hasil perkalian yang diperoleh adalah 2 × 0 × 26 × 28 = 0.

Agar menghasilkan 1456, kondisi perlu diperbaiki sehingga angka 0 tidak ikut diproses. Misalnya dengan menggunakan syarat arr[i] > 0. Setelah diperbaiki, hasilnya menjadi 2 × 26 × 28 = 1456.
